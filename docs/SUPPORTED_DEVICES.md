# Supported Devices

This table separates registry support from detection depth. “Target baseline” means the parser and high-priority security baseline have current effective-state tests. “Expanded static baseline” means the planned secondary-platform packs are closed but deliberately bounded by what the supported export proves. “Basic” means the format is registered but known parser or rule-depth work remains.

| Vendor | Device/OS | Parser | Detection status |
|---|---|---|---|
| Cisco | IOS | `CiscoIOSParser` | Target baseline |
| Cisco | IOS-XE | `CiscoIOSXEParser` | Target baseline |
| Cisco | ASA / PIX | `CiscoASAParser` | Target baseline |
| Fortinet | FortiGate / FortiOS | `FortiOSParser` | Target baseline; documented-default inference for 7.x, explicit-state analysis for older/unversioned exports, VDOM/global active-policy inspection-profile resolution, distinct IPv4/IPv6 local-in analysis, and same-VDOM attached IKE/IPsec proposal resolution |
| Check Point | Firewall-1 legacy management export | `CheckPointFW1Parser` | Target offline-policy baseline with bounded static subnet/range/protocol/port containment; dynamic, runtime and compiled-policy state remains out of scope |
| Juniper | Junos | `JunOSParser` | Target baseline; named-user login-class and CLI timeout resolution, pre/post-login notice separation, remote accounting and explicit J-Web session controls, plus distinct stateless-filter and SRX zone-pair policy models with static address/application resolution and attached/interface-bound IKE/IPsec reference resolution |
| Juniper | ScreenOS | `JuniperScreenOSParser` | Target baseline; platform is EOL. ScreenOS 6.3 exports additionally receive release-gated explicit default-policy and separate console/Telnet, WebUI, administrator-AAA, and policy/user auth-server timeout analysis |
| Palo Alto | PAN-OS XML | `PaloAltoPANOSParser` | Expanded static baseline; local administrator role/authentication/MFA evidence, explicit banner/session/lockout controls, attached PAN-OS 10+ management SSH profiles, management TLS/certificate policy, same-vsys/shared active-rule inspection-profile resolution, content scheduling and system logging verified; Panorama inheritance explicit unknown |
| HP / Aruba | ProCurve / ArubaOS-Switch running configuration | `HPProCurveParser` | Expanded static baseline; ordered service/SNMP/SSH/AAA/accounting/password/logging/NTP/DHCP-snooping state plus release-gated manager/operator credentials, per-channel login/enable methods, remote CLI/serial/WebAgent timeouts, MOTD and independent plaintext/TLS WebAgent state; general service defaults remain limited to AOS-S 16.10 and administrative defaults to verified 16.10/16.11 exports |
| SonicWall | SonicOS 7 E-CLI `show current-config custom` | `SonicOSParser` | Expanded static baseline; interface/rule/VPN/operations plus typed local administrator roles/MFA, authentication method/local fallback, password constraints, login/session controls, CLI banner, and active HTTPS TLS/certificate selection; 7.0-7.2 documented defaults are release-gated, 7.3 omissions remain unknown, and incompatible/legacy preference exports are rejected |
| Arista | EOS | `AristaEOSParser` | Expanded static baseline; active eAPI VRF/protocol/ACL/TLS-profile state, typed local-role resolution, ordered login/EXEC/command AAA and accounting, release-aware console/SSH/Telnet sessions, login banner, explicit management SSH algorithms/ACLs/empty-password policy, SNMPv3, logging and authenticated time |

The canonical IDs and accepted aliases are defined in `src/devices/registry.py`.

Eleven public pipelines are continuously checked by `scripts/run_full_regression.py`. Its 32 permanent inputs comprise the prior 20 target cases plus paired and edge-case configurations for all four secondary platforms. Registry reachability and expanded-baseline status do not imply universal vendor-version or full target-baseline parity. Static exports plus an explicit assessment time can establish offline certificate-material validity, but cannot prove the certificate currently served, revocation, active subscription/licensing state, runtime inspection, installed effective policy, negotiated VPN security associations, peer identity, or whether a software release is currently supported.
